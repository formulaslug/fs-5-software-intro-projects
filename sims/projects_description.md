# Simulations Intro Projects

## Project One:
Model the vehicle going through a turn at various speeds. Compute the required force for both the front axle and rear axle. Use the template provided which has the matplot animation code written.
* **Centripetal Force:** `(mass * velocity^2) / radius`
* **Front Axle Force:** `Centripetal Force * (b / L)`
* **Rear Axle Force:** `Centripetal Force * (a / L)`

## Project Two:
Using a friction coefficient (`μ`) of your choice, calculate the maximum friction force the tires can produce.Compare available friction force against force demands to figure out at which speed traction is lost (for both axles). Use the template provided which has the matplot animation code written as a function. Call the function once you are done writing your code.
* **Front Axle Capacity:** `μ * m * g * (b / L)`
* **Rear Axle Capacity:** `μ * m * g * (a / L)`
